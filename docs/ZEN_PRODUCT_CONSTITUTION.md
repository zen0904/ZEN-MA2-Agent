# ZEN Product Constitution

ZEN MA2 Agent is a show-making system, not merely a grandMA object generator.
The 100% goal is reliable, show-ready output across songs, rigs, venues and
incomplete information, with safe fallbacks and minimal operator rescue.

The durable flow is:

```text
intake (venue/show/inventory/constraints)
 -> normalized Rig Context
 -> Song/Performance Analysis
 -> Design Intent and Visual Strategy
 -> console programming intent
 -> typed ZEN_SHOW_PLAN
 -> resolvers -> deterministic Builder
 -> Preview -> Approval -> console -> read-back/verification
```

Correct visible output is necessary but not sufficient. Production quality also
requires reliability, native-console structure, cleanliness, maintainability,
editability, traceability, modification safety, live usability, operator
ergonomics and handover readability.

Current grandMA2 behavior and evidence remain bounded. Unsupported values,
geometry, or grammar are not inferred from names, binary data, or silence.
