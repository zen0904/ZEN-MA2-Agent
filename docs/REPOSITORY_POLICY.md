# Repository Policy

GitHub is durable source, history, documentation and verified knowledge
storage. It is not a bulk media, model, build or cache warehouse.

Use `LOCAL_FIRST_VERIFICATION` for routine tests/builds. Do not add expensive
per-push CI, Git LFS, or paid artifact/storage infrastructure without explicit
justification and approval. Keep source, Markdown knowledge, small deterministic
fixtures, reports, references and manifests; do not commit caches, build
outputs, temporary exports, large media, models or raw research collections.

Preserve history. No force push, reset, squash, rebase or deletion of existing
work without explicit approval. Keep local research/cache directories intact
when they are outside the committed source set.
